# گزارش فاز ۵ — AI Chat + دشبورد + دانلود (v0.5.0)

**تاریخ:** ۲۲ مرداد ۱۴۰۵ (۲۰۲۶-۰۸-۱۲) | **وضعیت:** کامل — E2E زندهی چت منتظر سهمیه/کلید پولی

## خلاصه
گفتوگوی هوشمند با چارت (Retrieval-based) + دشبورد مدیریت + دانلود گزارش.

## تغییرات
- `app/chat/intents.py` — طبقهبندیکنندهی اینتنت فارسی (۱۶ دسته: شغل، پول، رابطه، احساسات...) بدون LLM
- `app/chat/retrieval.py` — لایهی بازیابی: فقط فاکتورها + insight های مرتبط به LLM میرود (grounded)
- `app/chat/service.py` — چرخهی کامل: intent → retrieve → prompt → LLM → پاسخ
- `POST /api/chat` (با گیت پرداخت: فقط پلن خریداریشده) + `GET /api/chat/access/{chart_id}`
- `templates/chat.html` — حبابهای پیام RTL (Alpine)، قفل برای غیرخریدار
- `/admin` + `/api/admin/stats` — دشبورد: درآمد، وضعیت سفارشات، گزارشها
- دکمهی «💬 گفتوگو با چارت» در صفحهی چارت
- پیام خطای سهمیه بهجای پاسخ خالی

## تستها
- **۴۷ پاس** (۲۱ گلدن + ۱۱ گزارش + ۷ پرداخت + ۸ چت) — چت با FakeRouter بدون مصرف سهمیه
- **E2E کارگر ARQ تأیید شد:** هر دو گزارش صفشده توسط کارگر تولید شدند (13/13 + PDF) — کل زنجیرهی پرداخت→صف→تولید→PDF→دانلود

## هزینه
۰ تومان (تستها mock) — سهمیهی Gemini روزانه ۲۰/کلید؛ امروز با ۲ گزارش + تستها تمام شد

## Pending (نیازمند ورودی کاربر)
- **کلید DeepSeek روی سرور** (برای chat و گزارش در production) — فعلاً فقط از طریق opencode-go در دسترس است
- E2E زندهی chat (بعد از ریست سهمیه فردا یا کلید پولی)
- اتصال سفارش به کاربر OTP (فعلاً به profile متصل است)
