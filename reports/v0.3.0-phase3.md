# گزارش فاز ۳ — موتور گزارش (v0.3.0)

**تاریخ:** ۲۲ مرداد ۱۴۰۵ (۲۰۲۶-۰۸-۱۲) | **وضعیت:** در حال نهاییسازی

## خلاصه
موتور کامل تولید گزارش ۱۳ بخشی فارسی: Rule Engine داده-محور → Prompt Builder →
LLM (json_mode) → QA خودکار → PDF (WeasyPrint + Vazirmatn) + صف ARQ.

## تغییرات کلیدی
- **Rule Engine** (rules.py): ۷۵ قانون با Factor/Condition/Weight/InterpretationKey/Priority
  + قوانین جایگزین (fallback) برای پوشش ۱۳/۱۳ دامنه در هر چارتی
- **json_mode اجباری**: بدون `responseMimeType: application/json` مدل خروجی
  مخلوط markdown+JSON میدهد → QA همه را رد میکند (کشف تجربی 2026-08-12)
- **سهمیه فری Gemini = ۲۰ درخواست/روز/پروژه** → روتر قفل پیشگیرانه
  `_daily_quota=20/key`؛ یک گزارش ≈ ۱۳-۳۹ تماس → ~۱ گزارش کامل/روز با ۸ کلید
- **QA خودکار**: ۳ شکل evidence (factor/aspect-dict/aspect-string) + رد عامل جعلی +
  برج نادرست + عبارات ممنوع (پزشکی/غیب/قطعی) + حداقل طول (۴۰ کلمه/insight، ۱۵۰/بخش)
- **worker.py**: ARQ job → تولید → ذخیره در DB → رندر PDF
- **endpoint ها**: POST/GET /api/charts/{id}/report + GET /api/reports/{id}/pdf
- **UI**: دکمه «تولید گزارش» با Alpine polling روی صفحه چارت

## تست‌ها
- ۱۱ تست موتور گزارش با FakeRouter (بدون مصرف سهمیه) — همه پاس
- مجموع: ۳۲ پاس / ۳ skip
- تأیید کیفی ۱ بخش (identity): متن واقعی Gemini — خورشید اسد خانه ۱ + همنشینی ASC ✅

## هزینه
- سهمیه رایگان Gemini مصرف شد (۰ تومان)؛ DeepSeek پولی برای production لازم است
- زمان هر بخش با مدل thinking: ~۱۵-۳۰ ثانیه → کل گزارش ~۶-۱۲ دقیقه
