# گزارش فاز ۴ — تجاری (v0.4.0)

**تاریخ:** ۲۲ مرداد ۱۴۰۵ (۲۰۲۶-۰۸-۱۲) | **وضعیت:** کامل + E2E سندباکس تأییدشده

## خلاصه
لایهی تجاری: پلنهای فروش + درگاه زرینپال (سندباکس) + سفارشات + تولید خودکار گزارش پس از پرداخت.

## تغییرات
- `app/payment/zarinpal.py` — کلاینت API v4 (request/verify) با sandbox/production، خطاهای فارسی، amount به ریال
- `app/models.py` — جداول `plans` (۳ پلن: پایه ۱۴۹ / کامل ۳۴۹ / طلایی ۶۹۹ هزار تومان) و `orders` (pending/paid/failed)
- `app/main.py` — `/plans` صفحهی تعرفهها، `POST /api/orders` (ایجاد سفارش + درگاه)، `GET /api/payments/verify` (کال‌بک)، `/payment/result`، `GET /api/plans`، `GET /api/orders/{id}`
- بعد از پرداخت موفق: **تولید خودکار گزارش** (Report + صف ARQ + لینک به سفارش)
- `templates/plans.html` + `payment_result.html` — کارتهای پلن (موبایل ۳۹۰px) + صفحهی نتیجه
- `chart.html` — دکمهی «خرید گزارش کامل ✨» زنده شد + بررسی خودکار وضعیت گزارش
- فیکس سرریز افقی موبایل: `overflow-x:hidden` در base.html (حبابهای تزئینی بیرون از دید)
- `.env.example` — `ZARINPAL_MERCHANT_ID`, `ZARINPAL_SANDBOX`, `PUBLIC_BASE_URL`
- `tests/test_payment.py` — ۷ تست با کلاینت جعلی (بدون تماس واقعی)

## تستها
- **۳۹ پاس** (۲۱ گلدن + ۱۱ گزارش + ۷ پرداخت)
- **E2E زندهی سندباکس زرینپال:** سفارش → URL درگاه (S… authority) → پرداخت شبیهسازیشده → کال‌بک verify → **paid** (ref 422133106) → گزارش auto-queued ✓
- موبایل ۳۹۰px: صفحات پلن/نتیجه بدون اسکرول افقی ✓
