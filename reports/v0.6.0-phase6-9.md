# گزارش فاز ۶–۹ — رباتها + SEO + Share + Transits (v0.6.0)

**تاریخ:** ۲۲ مرداد ۱۴۰۵ (۲۰۲۶-۰۸-۱۲) | **وضعیت:** کامل — تستهای زنده تأیید شد

## خلاصه
رباتهای تلگرام/بله (دکمهای کامل) + سئو + کارت اشتراکگذاری + موتور گذر سیارات.

## تغییرات
1. **رباتها (تلگرام + بله):** هندلر دکمهای کامل — /start → «ساخت چارت» → تاریخ → ساعت → شهر →
   چارت محاسبه + کارت اشتراک + دکمههای (چارت / خرید / گذرها). جدول `bot_chat_states` +
   webhook با سکرت (فقط تلگرام؛ بله سکرت ندارد — pitfall v140).
2. **SEO:** sitemap.xml + robots.txt داینامیک + تگهای OG/description + JSON-LD.
3. **کارت اشتراک:** ۱۲۰۰×۶۳۰ رندر Chromium، کششده بر دیسک، endpoint `GET /api/share/{id}.png`.
4. **Transits:** موتور گذر سیارات بر چارت (صحرای نجومی محلی) + صفحه + API.
5. **زیرساخت تست:** دیتابیس تست جدا `chart_platform_test` (هرگز prod) + conftest.
6. **۲۴ کلید Gemini** (۹ قبلی + ۱۵ جدید) — سهمیهی روزانه ~۴۸۰ تماس.

## تستها (۵۵ پاس + ۳ skip)
- ربات: start / جریان کامل / تاریخ نامعتبر / لغو — با FakeBotAPI (بدون تماس واقعی)
- ترانزیت + کارت اشتراک: deterministic
- **زنده:** چت (جواب grounded واقعی با Gemini)، ترانزیت API، کارت PNG، هر دو webhook — همه 200/OK

## هزینه: ۰ تومان (سهمیهی فری)
