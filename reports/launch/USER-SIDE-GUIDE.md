# 📱 راهنمای اقلام سمت کاربر — ZAYCHE (فاز ۶)

> این اقلام فقط با حساب/دستگاه/اعتبار شما انجام میشوند. سمت فنی همهچیز آماده است؛ با ارائهٔ هر مورد، همان لحظه نصب و تست میشود.

## ۱) مرچنت واقعی زرینپال (الزامی برای پرداخت واقعی)
- **وضعیت:** سندباکس وصل و تست است؛ `ZARINPAL_MERCHANT_ID` سندباکس در `.env`، `ZARINPAL_SANDBOX=on`
- **قدمهای شما:**
  1. در [p.zarinpal.com](https://p.zarinpal.com) ثبتنام/ورود → «فروشگاه من» → درگاه پرداخت → **تأیید شده** (نیاز به مدارک شغلی)
  2. از پنل، **Merchant ID** فروشگاه تأییدشده را کپی کنید
  3. برای من بفرستید (فقط ID)
- **من انجام میدهم:** قرار دادن در `.env` (`ZARINPAL_MERCHANT_ID` + `ZARINPAL_SANDBOX=off`) → **تست E2E واقعی:** یک تراکنش ۱۰,۰۰۰ تومانی با کارت شتاب → callback → verify → active شدن اشتراک → گزارش. اسکریپت تست آماده است (`scripts/payment_e2e_test.py`).

## ۲) کلید کاوهنگار (SMS)
- **وضعیت:** کد جاوااسکریپت/بکاند آماده است؛ فقط کلید لازم است
- **قدمهای شما:** در [panel.kavenegar.com](https://panel.kavenegar.com) ثبتنام → «وبسرویس» → ساخت API Key → برای من بفرستید
- **من انجام میدهم:** `KAVENEGAR_API_KEY=` + تست ارسال یک SMS واقعی به شمارهٔ خودتان + لاگ تحویل.

## ۳) دامنهٔ نهایی (zayche.io یا…)
- **وضعیت:** سایت روی chart.negar.io است؛ CNAME آماده
- **قدمهای شما:** خرید دامنه (مثلاً zayche.io) از هر رجیسترار → DNS را روی CNAME به `chart.negar.io` بگذارید (یا NS به Cloudflare)
- **من انجام میدهم:** تنظیم vhost + SSL (Let's Encrypt) + ریدایرکت chart.negar.io → دامنهٔ جدید + آپدیت OG/معرفی + تست HTTPS از موبایل.

## ۴) برند/لوگو/favicon/OG
- **وضعیت: ✅ کامل شد (سمت من)** — بنر OG ۱۲۰۰×۶۳۰ ساخته و لایو شد (ستارهها + حلقهٔ زودیاک طلایی + «زایچه» + شعار «نقشهٔ تولد تو، راهنمای زندگی»)
- **قدم شما (اختیاری):** اگر طراح گرافیک دارید، لوگوی نهایی را بدهید تا جایگزین کنم. تا آن زمان لوگوی فعلی فعال است.

## ۵) تست موبایل واقعی (Android/iPhone)
- **وضعیت:** شبیهساز سبز است؛ تست واقعی فقط با گوشی شما
- **قدمهای شما:** ۵ دقیقه وقت: (۱) باز کردن سایت روی گوشی → چارت بسازید → گزارش بخرید (حتی رایگان/تستی) → (۲) چت بپرسید → (۳) ربات تلگرام و Bale را امتحان کنید
- **من انجام میدهم:** یک چکلیست ۲۰ موردی موبایل (فونت، دکمهها، اسکرول، پرداخت، خروجی PDF) میسازم که شما فقط ✅ بزنید.

## ۶) Push واقعی (اعلان)
- **وضعیت:** زیرساخت web-push (VAPID) آماده است (`.env` VAPID ست شده)
- **قدمهای شما:** بعد از تست موبایل — اجازهٔ نوتیفیکیشن در گوشی (یک دکمه در سایت)
- **من انجام میدهم:** تست واقعی push روی گوشی شما (یک اعلان آزمایشی + اعلان «گزارش آماده شد»).

## ۷) Search Console + ایندکس
- **وضعیت:** sitemap.xml و ۳۰ مقاله SEO لایو هستند
- **قدمهای شما:** [search.google.com/search-console](https://search.google.com/search-console) → افزودن ملک (دامنه یا پیشوند URL) → تأیید مالکیت (فایل HTML یا DNS) → submit sitemap
- **من انجام میدهم:** فایل تأیید (verification file) را میسازم و روی سایت میگذارم تا شما فقط کپی/پیست کنید + چک ایندکس شدن در گوگل.

## ۸) ارائهٔ اقلام — ترتیب پیشنهادی
1. مرچنت زرینپال (مهمترین — درآمد) ← بعد از آن تست E2E پرداخت واقعی
2. کاوهنگار ← تست SMS واقعی
3. دامنه ← انتقال + SSL
4. گوشی ← چکلیست ۲۰ موردی
5. push + Search Console ← همزمان با گوشی
