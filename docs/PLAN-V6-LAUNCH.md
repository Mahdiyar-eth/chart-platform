## فاز A — هویت برند

### A-1 تثبیت نام برند
نام نهایی در کل سایت (title، meta، OG، فوتر، ایمیل/نیوزلتر، favicon) یکدست شود.

### A-2 امضای بصری برند (B-5)
یک visual signature اختصاصی از مفهوم «نقشه آسمان در لحظه تولد» — نه لوگوی کلیشه‌ای ستاره/ماه.
عناصر پیشنهادی: مدار سیارات + مختصات تولد + نقطه مرکزی (تولد).
استفاده در: لوگو، کارت چارت، PDF، OG image، favicon، landing، جلد گزارش.

### A-3 لید مگنت + نیوزلتر (B-8)
- **لید مگنت:** «چارت رایگان + ۳ insight رایگان» (زیرساخت موجود است) → ایمیل/شماره → پیشنهاد گزارش کامل.
- **نیوزلتر:** هفته‌ای یک «نگاهی به آسمان هفته + تمرین تأمل» — تأملی و **غیرپیشگویانه** (محتوای زیرساخت آن موجود است: `sky_today` + `weekly_reflection`).
- **بستر:** تلگرام (کانال/بات) به‌عنوان بستر اصلی (ایمیل در ایران کم‌استفاده است — در «سوالات باز» ببینید).

## فاز B — محتوا (بخش اصلی این پلن)

### B-1 مقالات: ۵۰ مقاله درجه‌یک
1. **ممیزی ۳۴ مقاله موجود** — ناقص‌ها را کامل کن (پاراگراف‌های نیمه‌کاره، توضیح ناقص اصطلاحات).
2. **رساندن به ۵۰** — ۱۶ مقاله جدید که شکاف‌های SEO را پر کند.
3. **قانون محتوا:** هر اصطلاح تخصصی (house، transit، aspect، retrograde و...) کنارش **توضیح ساده‌ی عامه‌فهم** می‌آید — کاربر مبتدی بدون نیاز به فرهنگ لغت بفهمد.

### B-2 تصویر مقالات با FLUX
- هر مقاله یک تصویر هدر اختصاصی با `black-forest-labs/flux-dev` (طبق تصمیم ۳).
- سبک یکدست: نجومی/آسمانی، تیره با لهجه طلایی (هماهنگ با تم سایت).
- تصاویر در R2 (پیشوند `article-images/`) ذخیره و در OG image + هدر مقاله استفاده شود.

### B-3 SEO کامل مقالات
- **Meta کامل:** title + description یکتا برای هر مقاله.
- **Schema.org:** `Article` + `FAQPage` (برای مقاله FAQ) + `BreadcrumbList`.
- **لینک داخلی:** هر مقاله → ۲-۳ مقاله مرتبط + لینک به قیف (چارت رایگان / پلن).
- **Sitemap:** همه ۵۰ مقاله + صفحات `/learn` و `/signs` در sitemap (الان ۶۵ URL دارد).
- **Slug فارسیخوانا + کلمه کلیدی** در H1، پاراگراف اول، و alt تصویر.

### B-4 آموزش نجوم: رفع UI/UX + تکمیل
**مشکل فعلی:** قالب‌های `seo_index.html` (۵۰ خط) و `seo_page.html` (۲۷ خط) — رنگ و خوانایی ضعیف.
- **رفع UI/UX:** کنتراست رنگ (WCAG AA)، فاصله‌گذاری، سایز فونت خوانا، هدر/تیتر واضح، حالت موبایل.
- **تکمیل محتوا:** ۳۷ صفحه فعلی را از نظر محتوایی غنی‌تر کن (هر صفحه: توضیح ساده + مثال + ارتباط با چارت خودت + لینک داخلی).
- **ناوبری:** فهرست منظم سیاره‌ها/خانه‌ها/برج‌ها با آیکون.

### B-5 FAQ + راهنما + درباره: خیلی کامل‌تر
- **FAQ:** از ۳-۴ سوال → **۳۰+ سوال** دسته‌بندی‌شده (حساب، خرید، گزارش، نجوم، حریم خصوصی، استرداد، ربات).
- **راهنما:** آموزش گام‌به‌گام استفاده (ساخت چارت → خواندن گزارش → اشتراک → ربات) با تصویر/مثال.
- **درباره ما:** داستان برند + روش‌شناسی (Swiss Ephemeris + چرا خودشناسی نه فال) + تیم/تماس.

## فاز C — تست و لانچ

### C-1 تست کامل (قبل از لانچ)
- **تست روی موبایل واقعی مهدی** (نه شبیه‌ساز) — همه صفحات، فرم‌ها، دکمه‌ها.
- **ربات تلگرام + بله:** تست کامل فلوی اشتراک، چارت، پرداخت.
- **پرداخت زرین‌پال:** یک تراکنش واقعی آزمایشی (تست کامل، نه mock).
- **تست رگرسیون:** ۸۳ تست + تست دستی مسیرهای حیاتی.

### C-2 دیپلوی روی سرور جدید
**پیشنهاد من: Docker Compose + nginx روی هاست** (وب‌سرچ این را استاندارد FastAPI+Postgres+Redis تأیید کرد).

| گزینه | مزیت | عیب |
|---|---|---|
| **Docker Compose** (پیشنهاد) | قابل بازتولید، مهاجرت آسان، rollback ساده، ایزوله | سربار عملیاتی کم |
| bare-metal (فعلی) | ساده، امتحان‌شده | دستی، خطای انسانی، مهاجرت سخت‌تر |

**اجزای Docker:** `app` (FastAPI) + `worker` (ARQ) + `redis` + `postgres` — nginx روی هاست برای TLS (همان الگوی دامنه‌محور فعلی).

**تست قبل از دیپلوی (طبق خواسته تو):**
1. ساخت `docker-compose.yml` + `Dockerfile`
2. تست روی سرور فعلی (یا staging): ساخت ایمیج → اجرای استک → اجرای ۸۳ تست علیهش → verify `/health`
3. فقط وقتی همه‌چیز درست بود → دیپلوی روی سرور جدید

### C-3 لانچ واقعی
- دامنه + DNS + TLS روی سرور جدید
- منتقل‌کردن دیتای واقعی (بکاپ/restore تست‌شده)
- مانیتورینگ پایه + alert

## سوالات باز (برای Gemini / Claude — برای cross-check)

1. **Docker vs bare-metal برای یک VPS تکی با ترافیک کم:** آیا سربار عملیاتی Docker در این مقیاس واقعاً ارزشش را دارد، یا bare-metal با اسکریپت مهاجرت ساده‌تر است؟
2. **تصویر مقاله:** برای هدر مقاله‌های وبلاگ SEO، آیا `flux-dev` ($۰.۰۲۵) نسبت به `flux-schnell` ($۰.۰۰۳) ارزش ۸ برابر هزینه را دارد؟
3. **نیوزلتر در ایران:** با توجه به استفاده کم از ایمیل، آیا کانال تلگرام + ارسال در بات بهتر از خبرنامه ایمیلی است؟ (یا ترکیب هر دو)
4. **۵۰ مقاله:** آیا بهتر است اول ۱۶ مقاله‌ی جدید را با کلیدواژه‌های SEO هدفمند بسازیم و بعد ممیزی ۳۴ مقاله موجود را انجام دهیم (پیشنهاد من)، یا برعکس؟
