## ۳) تصمیمهای جدید تو (تغییر نسبت به V7)

### الف) «پلتفرم کامل اول، بعد ترافیک»
پیشتر B-7 (A/B قیمت) و G-4 (رفرال) و زیرساخت را «بعد از ترافیک» گذاشته بودم. **تغییر:** همه را **قبل از لانچ** کامل میسازیم تا پلتفرم از روز اول کامل باشد؛ فقط *اجرای* A/B تست و جمعآوری داده بعد از ترافیک واقعی است (چون به داده نیاز دارد).

### ب) نیوزلتر از طریق تلگرام و بله (نه ایمیل)
**شدنی است — و زیرساختش تقریباً آماده است.**
- ربات تلگرام (`@Astrology_chartx_bot`) و ربات بله از قبل موجودند.
- الان هم «آسمان هفته» هفتگی به مشترکین از طریق ربات پیام میدهد.
- **مکانیزم:** کاربر در سایت «دریافت هفتگی در تلگرام/بله» را انتخاب میکند → لینک اتصال (`/start` با کد یکبارمصرف) → `chat_id` ربات به اکانت سایت وصل میشود → پیام هفتگی به همان چت میرود.
- ایمیل صرفاً گزینهی ثانویه/اختیاری میماند.

### ج) تصاویر FLUX — هر دو مدل
- `flux-dev` ($۰.۰۲۵) → هدر مقاله + OG (کیفیت بالا، جایی که دیده میشود)
- `flux-schnell` ($۰.۰۰۳) → thumbnails/داخلی (کمکیفیتتر ولی کافی)
- هر تصویر **متناسب با متن، جذاب، SEO-شده** (alt متن، WebP، lazy-load، OG variant)

## ۵) Go/No-Go (خلاصه)

**GO:** همه تست بحرانی + مالکیت + پرداخت + fulfillment + بکاپ/restore + دیپلوی reproducible + رولبک + مانیتورینگ + محتوا کامل + بدون testimonial جعلی + موبایل پاس.
**NO-GO:** دسترسی با ID خالی + feature پولی بدون fulfillment + پرداخت جعلی + نشت گزارش + restore تستنشده + دیپلوی دستی + خطای نامرئی + محتوای placeholder + UI ناخوانا.
