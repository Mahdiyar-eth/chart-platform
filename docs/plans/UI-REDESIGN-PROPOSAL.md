# 🎨 پلن بازطراحی کامل UI — زایچه (پیش‌نویس برای تأیید)

> وضعیت: **منتظر تأیید مهدی — هیچ کدی هنوز زده نشده**
> منابع: ۳ اسکیل جدید نصب‌شده (ui-ux-pro-max با ۶۷ استایل/۱۶۱ پالت، kpi-dashboard-design، find-skills) + اسکیل‌های موجود (sketch برای ماکاپ، popular-web-designs، emil-design-eng، apple-design، design-system، responsive-admin-panel-ux)

## دامنهٔ کار — همهٔ صفحات

**کاربر:** فرود · محصولات · چارت · گزارش‌ها · خرید/پرداخت · سیناستری · امروز · کاوش · تنظیمات · حساب · تاریخچهٔ چت · ورود
**ادمین:** داشبورد KPI · تب‌های شش‌گانه · قیمت‌گذاری · اعطای دستی · سلامت · پرامپت‌ها · محتوا
**گزارش‌ها:** نمای لیست · نمای خواندن گزارش · پیشرفت تولید · حالت خطا

## روش اجرا (مطابق خواستهٔ تو)

1. **ماکاپ اول، نه کد** — برای هر گروه ۲–۳ طرح HTML کامل و قابل کلیک می‌سازم (sketch skill)
2. از هر طرح **اسکرین‌شات موبایل + دسکتاپ** می‌گیرم و همین‌جا می‌فرستم
3. **تو تایید می‌کنی** → بعد همان طرح به کد واقعی تبدیل می‌شود (صفحه‌به‌صفحه، هر بار تست+deploy)
4. گیت‌های همیشگی سر جایشان: page_gate، axe دو تم، brand gate

## ترتیب پیشنهادی گروه‌ها
1. داشبورد کاربر + گزارش‌ها (قلب محصول)
2. ادمین (۶ تب)
3. خرید/پلن‌ها
4. صفحات محتوایی باقی‌مانده

**زمان تقریبی هر گروه:** ماکاپ ~۲۰ دقیقه، اجرا بسته به تعداد صفحه.
