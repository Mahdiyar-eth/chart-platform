## ۲. پاسخ مستقیم: چرا هیچ تغییری در UI/UX نمی‌بینی

### دلیل اصلی: **UI عملاً تغییر نکرده — فقط محتوا تغییر کرده**

در کل پروژهٔ PLAN-MASTER (از `2b3e2f7` تا `6739d5c`)، تمام تغییر CSS این است:

```
app/static/css/  →  ۲۳ خط اضافه، ۱ خط حذف
کل CSS پروژه    →  ۱۱۷۲ خط
                    یعنی ۲٪
```

و آن ۲۳ خط فقط افکت شیشه‌ای (`saturate` + `box-shadow` + یک لایهٔ `::before`) است.

**هیچ‌کدام از این‌ها عوض نشده‌اند:** پالت رنگ · فونت و اندازه‌ها · مقیاس فاصله‌ها ·
شکل کارت‌ها · شعاع گوشه‌ها · ساختار چیدمان · ترتیب بخش‌ها · نوار بالا · نوار پایین.

دو اسکرین‌شات کنار هم (قدیم/جدید، هر دو ۳۹۰px) این را نشان می‌دهند: **زبان بصری
بایت‌به‌بایت یکسان است.** آنچه اضافه شده «بلوک محتوای بیشتر» است، نه «طراحی جدید».

پس حسِ تو درست است. W12 اسمش «لیکوییدگلس واقعی» بود ولی در عمل یک افکت
جزئی روی کارت‌هاست، نه بازطراحی.

### اما متن‌ها **واقعاً** عوض شده‌اند — با اندازه‌گیری

متن دیدنی (`inner_text`) هر صفحه در دو نسخه استخراج و diff شد:

| صفحه | خطوط تغییرکرده | از کل |
|---|---|---|
| `/` (فرود) | **۳۳** | ۱۸۴ |
| `/plans` | **۱۰۹** | ۱۷۸ |
| `/synastry` | ۱۲ | ۷۳ |
| `/today` | **۴** | ۵۹ |

نمونهٔ واقعی از diff صفحهٔ فرود:
```
- گزارش کامل — از ۱۴۹ هزار تومان
+ با اعتبار باز کن — از یک اعتبار   … نرخ مرجع: هر اعتبار ۵۰ هزار تومان
- ۳ حوزه‌ی زندگی / Big Three / گفتگو با AI / سیناستری / ترانزیت ۴ ماهه
+ یک سؤال، یک جواب — ۱ / آشنایی ۵ بخش — ۳ / شناخت کامل — ۷ / چارت سالیانه — ۹ …
+ سؤال کاربر: «آیا شغلم را عوض کنم؟»          ← بلوک «نمونهٔ واقعی خروجی»
```
`/today` عملاً دست‌نخورده مانده (۴ خط از ۵۹) با اینکه «امروزِ تو» محصول جدید W5 است.

### تست ۵ ثانیه‌ای برای اینکه بفهمی prod به‌روز است یا نه

خروجی شبکه از محیط من به `chart.negar.io` مسدود است، پس نمی‌توانم مستقیم چک کنم.
این رشته‌ها **فقط** در بیلد جدید وجود دارند (در قدیم صفرند):

| صفحه | رشته | جدید | قدیم |
|---|---|---|---|
| `/` | «آیا شغلم را عوض کنم» | ۱ | **۰** |
| `/` | «نمونه‌ی واقعی خروجی» | ۱ | **۰** |
| `/plans` | «شناخت کامل» | ۲ | **۰** |
| `/plans` | «نرخ مرجع» | ۱ | **۰** |
| `/plans` | «چارت سالیانه» | ۲ | **۰** |

**اگر روی `chart.negar.io` این‌ها را نمی‌بینی ⇒ prod به‌روز نیست** (Ctrl+Shift+R بزن؛
Jinja تا `systemctl restart chart-web chart-worker` کش می‌ماند).
اگر می‌بینی ⇒ prod درست است و مسئله همان چیزی است که بالا نوشتم: طراحی عوض نشده.

## ۳. یافته‌های جدید این دور

### 🔴 N1 · صفحهٔ چارت هنوز **قیمت تومانی قدیمی** را نشان می‌دهد

`app/templates/chart.html:162-166` — روی همان صفحه‌ای که هر کاربر رایگان به آن می‌رسد:
```html
<span class="chip">پایه ۱۴۹ هزار</span>
<span class="chip">استاندارد ۳۴۹ هزار</span>
<span class="chip">پرمیوم ۶۹۹ هزار</span>
<a class="btn btn-lg" href="/plans?chart=...">خرید گزارش کامل</a>
```
کاربر روی صفحهٔ چارت **تومان** می‌بیند، دکمه را می‌زند، و در `/plans` **اعتبار**
(۳ / ۷ / ۱۴) می‌بیند — برای همان محصولات. این دقیقاً همان «دو ارز موازی» است که
کل پروژه قرار بود حذفش کند، و روی مهم‌ترین صفحهٔ قیف نشسته.
W11 و W13 فقط `index.html` را دست زدند و این بلوک را ندیدند.
**در اسکرین‌شات `chart-new-390.png` پایین صفحه کاملاً دیده می‌شود.**

### 🟡 N2 · `synastry_full` «بازنشسته» اعلام شد ولی هنوز فروخته می‌شود
کامنت کد می‌گوید `retired from sale` و kind اختصاصی گرفت، اما در کاتالوگ همچنان
`active=True` است و در `/plans` کارت سومش رندر می‌شود:
```
synastry_love ۸ · synastry_work ۸ · synastry_full ۱۰   ← هر سه فعال
```
حالا بدتر هم شده: خریدار ۱۰ اعتباری قبلاً kind `synastry` می‌گرفت که همه‌چیز را باز
می‌کرد؛ الان فقط خودش را باز می‌کند. یعنی **گران‌ترین محصول کمترین چیز را می‌دهد**
و سه کارت تقریباً یکسان کنار هم در `/plans` نشسته‌اند.

### 🟡 N3 · پلن‌های تومانی قدیمی هنوز سفارش‌پذیرند
`basic ۱۴۹k` · `full ۳۴۹k` · `gold ۶۹۹k` · `synastry ۴۹۹k` همگی `active=True` با
`credits_grant=0`. در `/plans` نمایش داده نمی‌شوند، اما API قبولشان می‌کند:
```
POST /api/orders {monthly} -> 404   ← درست، بازنشسته شده
POST /api/orders {full}    -> 502   ← فقط چون درگاه اینجا تنظیم نیست؛ سفارش پذیرفته شد
```

## ۴. جمع‌بندی

**فیکس‌های R12: ۸ از ۸ واقعاً بسته.** این را با اجرا تأیید کردم، نه از روی گزارش.

**اما پاسخ سؤال تو:** تغییری نمی‌بینی چون **تغییر بصری‌ای وجود ندارد** —
۲٪ CSS، بدون تغییر در رنگ/فونت/فاصله/چیدمان. آنچه انجام شده بازنویسی **متن و
محتوا** بوده (که واقعی و قابل‌اندازه‌گیری است: ۱۰۹ خط از ۱۷۸ در `/plans`)، نه
بازطراحی رابط. اگر انتظار «ظاهر جدید» داشتی، آن کار هنوز انجام نشده است.

سه چیز که باید تصمیم بگیری:
1. **N1 را همین حالا ببند** — قیمت تومانی روی صفحهٔ چارت، تناقض مستقیم با کل مدل اعتباری است.
2. **یکی از سه سیناستری را بردار** (پیشنهاد: `synastry_full` را `active=False` کن).
3. **اگر واقعاً بازطراحی می‌خواهی، باید یک تسک جدا باشد** — با پالت، مقیاس تایپوگرافی
   و شبکهٔ فاصله‌ها به‌عنوان خروجی. «افکت شیشه‌ای» بازطراحی نیست و نباید به‌جای آن حساب شود.
