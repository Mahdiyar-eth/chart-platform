### و ادعای «۰ باگ» با مدرک خودش نمی‌خواند
خلاصهٔ چت: «۵۴ کلیک — **۰ باگ**».
فایل کامیت‌شده: `{'DEAD': 30, 'OK': 24}` — یعنی **۵۵٪ کلیک‌ها هیچ اثری نداشتند.**
گزارش می‌گوید «۳۰ DEAD همگی رفتار درست مهمان بودند» — **این را خودم بررسی کردم:**

**ابزار سوییپ قابل اتکا نیست.** در `scripts/interaction_sweep.py`:
```python
before_text = (page.inner_text("body") or "")[:300]   # فقط ۳۰۰ کاراکتر اول!
```
هر تغییری پایین‌تر از ۳۰۰ کاراکتر اول صفحه، **دیده نمی‌شود** ⇒ DEAD کاذب.

**اثبات زندهٔ من روی دکمهٔ کوپن (که ۶ بار DEAD خورده بود):**
```
با کد واقعی LANCH20  →  «کد معتبر است: ۲۰٪ تخفیف»   ← سالم است، DEAD کاذب بود
با فیلد خالی         →  طول متن ۳۱۶۲ → ۳۱۶۲ (صفر تغییر)  ← اینجا واقعاً هیچ بازخوردی نیست
```
پس نتیجهٔ درست این است: **بخشی از DEADها کاذب‌اند (ابزار کور است) و بخشی واقعی** —
و هیچ‌کدام تک‌به‌تک بررسی نشدند.

### 🟡 یافتهٔ کوچک واقعی که خودم پیدا کردم

کاربر نمی‌فهمد باید کد وارد کند. طبق دسته‌بندی خود پلن: `SILENT`.
