## 🟡 یافتهٔ جدید — واژه‌نامه ساخته شد ولی **هیچ لینکی به آن نیست** (صفحهٔ یتیم)

**شدت:** کوچک — ولی ارزش `T2` را تقریباً صفر می‌کند.

`/glossary` زنده و باکیفیت است: **۲۰۰ · ۷۹KB · ۱۱۹ anchor · ۴۲ لینک عمیق به `/learn` و `/signs`**
و در sitemap هم هست. اما **هیچ‌چیز به آن لینک نمی‌دهد:**

```
grep -rln 'href="/glossary' app/templates/ app/seo/   →  هیچ قالبی

لینک زنده به /glossary:
  /                                  → 0
  /articles                          → 0
  /learn                             → 0
  /faq                               → 0
  /articles/mercury-in-birth-chart   → 0
  /signs/asad                        → 0
  /moon-in/hout                      → 0
```

**تناقض با گزارش:** گزارش دور ۷ می‌گوید «۷۸ اصطلاح … **لینک از مقالات**».
من از صفحات فهرست **و** صفحات جزئیات مقاله بررسی کردم — **صفر لینک**.
لینک‌ها **یک‌طرفه‌اند**: واژه‌نامه به `/learn` و `/signs` لینک می‌دهد، ولی هیچ‌کس به واژه‌نامه.

**چرا مهم است:**
1. **SEO:** صفحه‌ای که هیچ لینک داخلی ندارد، عملاً هیچ اعتباری از سایت نمی‌گیرد —
   حتی اگر در sitemap باشد. ۷۹KB محتوای خوب بدون بازده می‌ماند.
2. **کاربر:** هیچ مسیری برای رسیدن به آن وجود ندارد؛ فقط با تایپ مستقیم URL.
3. **هدف اصلی `F3` پلن:** «هر اصطلاح تخصصی در اولین ظهور توضیح ساده داشته باشد» —
   واژه‌نامه قرار بود مقصد آن لینک‌ها باشد، نه یک جزیره.
