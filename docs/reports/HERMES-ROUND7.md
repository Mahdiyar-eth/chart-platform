## یافتهٔ بازبین (R7): باگ بازگشت اعتبار تحلیل گذر — P1 مالی

بازبین با اجرای قیف واقعی پول (و نه فقط تست) به دفتر اعتبار نگاه کرد و این را دید:

```
 amount |               reason
--------+------------------------------------
     25 | topup
     -7 | report_full
     -2 | transit_3m
      2 | transit_3m partial QA refund (5/8)   ← ۵ از ۸ شکست، ولی کل مبلغ برگشت
```

**ریشه:** `total_ev = len(events)` (همهٔ رویدادها) در حالی که فقط n رویداد روایت می‌شود
(`m["events"] == len(top) == n`). پس شرط «بازگشت کامل iff `failed_n >= total_ev`» هرگز درست
نمی‌شد و مخرج `ceil(price*failed/total_ev)` فراتر از سهم عادلانه بود.

**سناریوی قطعی (۵ اعتبار، ۱۲ماهه، چارت ۳۰ رویدادی، همهٔ ۱۲ روایت gate رد شوند):**
- OLD: `ceil(5×12/30) = 2` ← کاربر ۵ داد، هیچ نگرفت، فقط ۲ برگشت (ضرر خالص ۳ اعتبار ≈ ۱۵۰هزار تومان)
- NEW: `12 >= 12` → بازگشت کامل **۵** ✅
