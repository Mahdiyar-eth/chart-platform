## باگ‌های واقعی پیدا و رفع‌شده (نه صرفاً ظاهری)

1. **relocation.html** — تابع Alpine `relocApp()` متد `init()` نداشت → کرش JS واقعی در مرورگر (تأیید با تست واقعی)
2. **today.html** — وقتی fetch کند بود، `status?.streak` مقدار `undefined` روی صفحه چاپ می‌شد (بج streak) → با `?? 0` رفع شد
3. **today.html** — بج `best_streak` که بک‌اند هرگز برنمی‌گرداند (کد مرده، مقایسه با CODEBUNDLE قدیمی تأیید شد) → حذف شد
4. **error.html (404/500)** — تمام سایت با کلاس‌های خام Tailwind بی‌استایل رندر می‌شد چون هیچ‌جای دیگر Tailwind لود نمی‌شود → بازسازی کامل با گرامر Observatory
5. **admin save buttons** — از accent بنفش (`--accent`) به‌جای طلایی استاندارد سایت استفاده می‌کردند → یکدست‌سازی شد
6. **/plans FAQ heading** — نقض واقعی WCAG (کنتراست ۱.۰۶ در برابر حداقل ۴.۵) با axe-core پیدا شد؛ `--gold-ink` (رنگ متن روی دکمهٔ طلایی) مستقیم روی پس‌زمینهٔ تیره استفاده شده بود → به `--txt` تغییر یافت
7. **perf** — استایل‌شیت اضافه (`zayche-redesign.css`) یک درخواست HTTP اضافه به critical path اضافه کرده بود؛ FCP صفحهٔ اصلی مرزی (۲۸۰-۳۴۸ms در برابر بودجهٔ ۳۰۰ms) بود → merge در utilities.css، بعد از آن FCP پایدار ۲۸۰-۲۸۸ms
