# برند زایچه — سند هویت (G7)

## نام
**زایچه** — تنها نام رسمی در محصول، رابط کاربری، متادیتا و ارتباطات.
(در برخی اسناد داخلی قدیمی «چارت‌نگار» آمده؛ مرجع نیست.)

## پالت
| نقش | توکن | مقدار |
|---|---|---|
| پس‌زمینهٔ پایه | --bg | #0b1026 |
| سطح شیشه‌ای | --glass | rgba سفید کم‌آلفا روی bg |
| طلایی برند | --gold | #f5c518 → #e08e0b (گرادیان CTA) |
| متن اصلی | --text | #eef1fb |
| متن فرعی | --muted | #a8b3d4 |
| حالت روشن | data-theme="light" | bg #f4f5fb، متن سرمه‌ای |

قانون: طلایی فقط برای اقدام اصلی و تأکید؛ هرگز برای متن بدنه.

## تایپوگرافی
- Vazirmatn (400/500/700/800) — `font-display: optional` + preload Regular/Bold.
- h1 تا 2rem موبایل / 2.6rem دسکتاپ؛ بدنهٔ حداقل 16px.

## لحن
تأملی · صادق · مبتنی بر شاهد · محترم به اختیار کاربر.
- می‌گوییم: «محاسبه بر پایهٔ Swiss Ephemeris»، «این یک بینش است، نه حکم».
- نمی‌گوییم: قضاوت سرنوشت، وعدهٔ قطعی، ترساندن.

## ممنوعیت‌ها (اعتماد = تمایز)
- هیچ testimonial ساختگی، هیچ عدد کاربر غیرواقعی، هیچ گواهی جعلی.
- به‌جایش: نمونهٔ گزارش واقعی، شفافیت روش محاسبه، سیاست استرداد روشن.
