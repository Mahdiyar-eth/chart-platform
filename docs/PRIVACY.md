# حریم خصوصی و نگهداشت داده (ZAYCHE / زایچه)

سند واحد سیاست داده — audit r4 C6. نسخه: 2026-08-14

## ۱) چه داده‌هایی ذخیره می‌شود

| نوع | ستون‌های کلیدی | هدف |
|-----|---------------|-----|
| BirthProfile | نام، تاریخ/ساعت/شهر تولد | محاسبه چارت |
| Chart | مختصات نجومی، زودیاک، خانه‌ها | نمایش و تفسیر |
| ChatMessage | پرسش/پاسخ + گزارش_id | چت اختصاصی |
| Report + LLMRun | متن تفسیر، پرامپت/هزینه | گزارش‌ها |
| Order/Subscription | مبلغ، درگاه، وضعیت | پرداخت و اشتراک |
| Referral* | کد دعوت | رفرال |
| User | شماره موبایل (ورود کد یک‌بارمصرف) | احراز هویت |

تلفن/کد یک‌بارمصرف: ارسال پیامک فقط برای ورود (PayamResan) — بدون استفاده تبلیغاتی.

## ۲) ارسال داده به هوش مصنوعی (شفافیت)

- **سرویس‌های**: DeepSeek (API مستقیم) و OpenCode Go (درگاه OpenAI-compatible) — نه OpenAI.
- **چه چیزی ارسال می‌شود**: ساختار چارت (سیارات/خانه‌ها/زوایا) + متن پرسش کاربر (چت) یا درخواست تفسیر (گزارش).
- **ذخیره نمی‌شود**: نزد سرویس AI داده نگهداری/بازآموزی نمی‌شود؛ چت‌ها در DB خودمان با SECRETS_MASTER_KEY رمز می‌شوند.
- **خاموشی**: در محیط تست `ENRICH_INSIGHTS=0`؛ در prod اگر سرویس AI در دسترس نباشد پاسخ جایگزین (بدون AI) داده می‌شود.

## ۳) نگهداشت (Retention) — خودکار

| داده | مدت | مکانیزم |
|------|-----|---------|

| گزارش PDF (R2 `chart-reports/`) | نامحدود تا حذف حساب | — |

## ۴) حذف حساب (حق فراموش شدن)

`POST /account/delete` (با CSRF + ورود) همه را cascade حذف می‌کند:

- User + BirthProfile ها + Chart ها
- ChatMessage ها، Report ها + LLMRun ها + **فایل‌های PDF/صوتی از R2** (`delete_object`)
- Order ها (اصلی + سیناستری secondary)، Subscription ها، WeeklyReflection ها
- ReferralEvent ها + ReferralCode ها
- audit log ثبت می‌شود (`account.delete`) برای پاسخ‌گویی

باقیمانده: ردیف audit (بدون داده شخصی، فقط شناسه و زمان) و سفارش‌های مالی که قانوناً باید نگهداری شوند.

## ۵) امنیت داده در حالت سکون

- بکاپ‌ها: zip + age-encrypt (کلید خصوصی فقط روی سرور، `/root/.hermes/keys/chart-platform-age.txt`).
- محتوای چت: رمز Fernet با SECRETS_MASTER_KEY از `.env` (بکاپ در `/root/.hermes/keys/`).
- R2: باکت خصوصی `zayche-storage`؛ دسترسی فقط presigned (TTL ۳۰ دقیقه).
