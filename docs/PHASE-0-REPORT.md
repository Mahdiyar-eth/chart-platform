## 🔴 P0 — باید قبل از لانچ رفع شود

### ۱) IDOR — صفحه چارت و preview بدون مالکیت
`/chart/{id}` و `/api/charts/{id}/preview` با UUID تنها (بدون توکن/کوکی) → **200** برمیگردن. یعنی هر کس که ID چارت رو بدونه، داده تولد + Big Three + تفسیر شخصیت رو میبینه.

- ✅ گزارش/PDF/DOCX/audio **درست گیت شدن** (با `_report_gate` + تست)
- ❌ صفحه چارت + preview + share PNG **گیت نشدن**

### ۲) «حوزههای مورد علاقه» — وعدهی شکسته
فرم میگه «ترتیب و تأکید گزارش رو شخصیسازی میکنه» ولی فقط توی چت استفاده میشه، نه گزارش.

### ۳) «سؤال شخصی» — وعدهی شکسته (بدتر)
فرم قول میده «در گزارش کامل جوابش تفسیر میشه» ولی:
- JS فرم `question` رو به FormData **اضافه نمیکنه** (فقط `focus_areas` میفرسته)
- API هم پارامتر `personal_question` نداره
- سؤال حتی از مرورگر بیرون نمیره، ذخیره و جواب داده نمیشه
